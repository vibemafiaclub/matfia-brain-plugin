# 마피아MCP · 기획 잡기

> 이 스킬은 마피아MCP 연결이 필요합니다. search_cards 도구가 보이지 않으면 진행하지 말고 "마피아MCP를 먼저 연결해 주세요: https://www.vibemafiaclub.com/brain#connect"라고 안내하세요.
> 이 파일은 자동 생성됩니다(원본: context-hub packages/db/src/brain-skills.ts). 직접 고치지 마세요.

사용자가 만들고 싶은 것: $ARGUMENTS (비어 있으면: 사용자가 방금 말한 만들고 싶은 것)

바로 기능 목록을 만들거나 코드를 쓰지 말고 마피아MCP로 기획부터 잡으세요.
1. search_cards를 stage=요청파악으로 불러, 이 요청에서 먼저 확인해야 할 것(누가·어떤 장면에서·무엇이 되면 성공인지)을 정합니다.
2. 첫 버전 범위를 정할 때 search_cards를 stage=기획으로 다시 부릅니다. 기술적으로 어렵거나 검증 전에 필요 없는 것은 우선순위를 낮추자고 제안합니다.
3. 결과는 ①한 줄 목표 ②첫 버전에 넣을 것 3~5개 ③뒤로 미룰 것과 이유 ④사용자가 정해야 할 것(기본값·추천안을 붙여 한 번에)으로 정리합니다.
4. 근거로 쓴 카드 제목을 한 줄씩 밝힙니다.
